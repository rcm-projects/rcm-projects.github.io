Arena website source

Files
- index.html: page content and structure
- style.css: colors, typography, layout, and responsive styles
- script.js: utility AI illustration and combat-loop interactions

Preview
Open index.html in a browser. Keep all three files in the same folder.
An internet connection loads the Google Fonts used by the design; fallback fonts work offline.

Editing
Replace the labeled gameplay placeholders in index.html with your own images or videos.
The AI scores are illustrative rather than recorded game telemetry.

These files can be hosted on any static website host. Changes to this copy do not automatically update the live Sites website.
